# Säulenwächter

Die 3-Säulen-Strategie (Welt 40 % · Gold 30 % · Euro-Anleihen 30 %) für Home Assistant: Monatsentscheidung,
Trade-Republic-Depot (nur lesend), klare Anweisungen und WhatsApp-Meldungen. Die Oberfläche liegt in der
Seitenleiste, die Werte stehen als `sensor.saeulenwaechter_*` zur Verfügung.
